# Raw data

The raw HCMST public-use dataset is intentionally not redistributed in this repository.

Obtain the public-use HCMST 2017/2020/2022 data from ICPSR (DOI: `10.3886/ICPSR38873.v1`) and place this exact file here:

`HCMST 2017 to 2022 small public version 2.2.dta`

Expected SHA-256 for the analysis copy:

`a76c1ef8e14a69951db3d71142dfb3866063c7af8d0da67942b744e2727aeb56`

Run `python src/00_verify_data.py` before reproducing the analysis.
